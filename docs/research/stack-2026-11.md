## Quality stack

cargo-nextest, insta (replace/dictionary pipeline), proptest (replace engine, newline strip, token counter), cargo-llvm-cov (report, not a gate), cargo-deny (licences, advisories, bans), cargo-machete, clippy pedantic with a short allow list, typos-cli, i-slint-backend-testing pinned to the slint version, conventional PR titles, release-plz (publish = false).

Whisper regression in CI: CPU build, ggml-tiny.bin cached with SHA256 check, transcribe whisper.cpp `samples/jfk.wav`, assert normalised text under a WER threshold, never an exact snapshot.

## Signing (later)

- SignPath Foundation (free for OSS) requires an OSI licence and no proprietary parts; the Slint royalty-free licence may not pass. Ask them first, or use Slint under GPLv3 for that.
- Azure Artifact Signing from $9.99/month; individual eligibility limited.
- Apple Developer ID $99/year, notarization, hardened runtime, audio-input entitlement.
